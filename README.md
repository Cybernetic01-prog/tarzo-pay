# Tazro - Modern Fintech App

Tazro is a fully responsive, professional fintech web application built with React, Tailwind CSS, and Framer Motion. 

## Features

- **Onboarding Flow**: 3-slide interactive carousel explaining the core value propositions.
- **Identity Management**: Sleek toggle-based Auth system for signing in and getting started.
- **Financial Dashboard**:
  - Multi-currency support with real-time symbol switching.
  - Quick action buttons for high-velocity tasks (Send, Bills, Exchange).
  - Detailed transaction history with status indicators.
- **Apple-esque Design**: Soft purple accents, high border-radius (24px), and refined typography using Lexend and Inter.

## Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Development

The application uses Vite for fast development and building. The theme and brand colors are configured in `src/index.css` using Tailwind's CSS variable system.

- **Main entry point**: `src/main.tsx`
- **Application logic**: `src/App.tsx`
- **Styles**: `src/index.css`
